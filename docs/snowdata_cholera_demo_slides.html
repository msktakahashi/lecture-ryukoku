今日の問い

まずは、死亡地点を地図に表してみます。

図から仮説を立てる

学生への問い：

死亡地点の分布を見ると、どの井戸が感染源として疑われるでしょうか。
その理由は何でしょうか。

ここでのポイント：

  • 図を見る
  • パターンを発見する
  • 仮説を立てる

「近い」を数値にする

地図を見ると、ある井戸の近くに死亡地点が集中しているように見えます。

では、

「井戸に近い」とは、データ上どのように表せばよいでしょうか。

ここでは、疑わしい井戸から各死亡地点までの距離を計算します。

疑わしい井戸を選ぶ

ここでは例として、死亡者数で重みづけした中心に最も近い井戸を、 「疑わしい井戸」の候補として選びます。

center_e <- weighted.mean(cholera_cases$Easting,
                          cholera_cases$Count)
center_n <- weighted.mean(cholera_cases$Northing,
                          cholera_cases$Count)

suspected_pump <- pump_locations |>
  mutate(
    distance_to_center =
      sqrt((Easting - center_e)^2 +
             (Northing - center_n)^2)
  ) |>
  slice_min(distance_to_center, n = 1)

距離変数を作る

cholera_cases2 <- cholera_cases |>
  mutate(
    distance_to_pump =
      sqrt((Easting - suspected_pump$Easting)^2 +
             (Northing - suspected_pump$Northing)^2)
  )

係数を解釈する

回帰式は次のように表せます。

[ 死亡者数_i = + 井戸からの距離_i + u_i ]

() が負であれば、

井戸から遠い地点ほど、死亡者数が少ない

という関係を表します。

ここで考えるべきこと

では、この回帰結果から、

この井戸の水がコレラを引き起こした

と結論づけられるでしょうか。

答えは、そう簡単ではありません。

この分析の限界

このデータで観察しているのは、 少なくとも1人の死亡者が出た地点です。

したがって、この回帰は、

井戸に近い人ほど死亡しやすい

ことを直接示しているわけではありません。

さらに必要なデータ

より厳密に考えるには、次のような情報が必要です。

  • 各地点に住んでいた人数
  • 死亡しなかった人の情報
  • 各世帯が実際に使っていた井戸
  • 所得や衛生環境
  • 直線距離ではなく、実際の移動距離

因果関係を考える

回帰分析の結果は、関係を数値で表すうえで有用です。

しかし、

関係があること

と

原因であること

は同じではありません。

この違いを意識することが、データ分析では重要です。

学生に出す演習問題：基礎

  1. cholera_cases の観測地点数を確認しなさい。
  2. 死亡者数の合計を求めなさい。
  3. 死亡地点を散布図で表しなさい。
  4. 井戸の位置を地図に追加しなさい。

学生に出す演習問題：応用

  1. 地図から、感染源として疑われる井戸を1つ選びなさい。
  2. その井戸から各死亡地点までの距離を計算しなさい。
  3. 距離と死亡者数の関係を散布図で確認しなさい。
  4. lm() を使って、距離と死亡者数の関係を推定しなさい。

学生に出す演習問題：考察

  1. 回帰係数を自分の言葉で解釈しなさい。
  2. この分析から言えることと言えないことを整理しなさい。
  3. 因果関係を明らかにするには、どのような追加データが必要でしょうか。
  4. 今回の分析を、現代の感染症対策に応用するとしたら、どのようなデータが必要でしょうか。
