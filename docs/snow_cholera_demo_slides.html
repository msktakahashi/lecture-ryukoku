今日のミニ演習

問い：

1854年、ロンドンのソーホー地区でコレラが流行しました。
死亡地点と井戸の位置から、感染源を推測できるでしょうか。

この問いを、Rを使って考えていきます。

使うデータ

今回は HistData パッケージに含まれるデータを使います。

library(HistData)
library(ggplot2)

主に使うデータは次の3つです。

  • Snow.deaths：コレラ死亡地点
  • Snow.pumps：井戸の位置
  • Snow.streets：道路の情報

まず、道路だけを描いてみます。

  geom_path(
    data = Snow.streets,

    linewidth = 0.3
  ) +
  coord_fixed() +
  theme_void()

次に、コレラによる死亡地点を追加します。

ggplot() +

ggplot() +

図から何が読み取れるか

この地図を見ると、死亡地点が特定の井戸の周辺に集中しているように見えます。

ここで学生には、次のように問いかけます。

どの井戸が感染源として疑われるでしょうか。
その理由は何でしょうか。

図で見えた関係を数値で考える

可視化によって、死亡地点と井戸の位置に関係がありそうだと分かりました。

次に考えるべきことは、

この関係を、数値としてどのように確認できるか

です。

ただし、ここで重要な注意点があります。

このデータだけで回帰できるか

Snow.deaths には、死亡した人の地点だけが含まれています。

つまり、次の情報は含まれていません。

  • その地域に住んでいた人数
  • 死亡しなかった人の情報
  • 各世帯が実際に使っていた井戸
  • 所得や衛生環境などの背景要因

したがって、このデータだけで

井戸に近いほど死亡しやすい

と厳密に分析することはできません。

回帰分析に必要なデータを考える

仮に地点ごとに死亡者数や人口が分かれば、次のような分析が考えられます。

[ 死亡者数_i = + Broad Street Pumpからの距離_i + u_i ]

ここで、() が負であれば、

Broad Street pumpに近い地点ほど死亡者数が多い

という関係を示唆します。

回帰結果をどう解釈するか

仮に、Broad Street pumpからの距離と死亡者数に強い関係が見つかったとします。

しかし、そこから直ちに

Broad Street pumpの水がコレラを引き起こした

と結論づけてよいでしょうか。

因果関係を考える

注意すべき点があります。

  • 人口密度が高い場所ほど死亡者数も多いかもしれない
  • 貧困や衛生環境が関係しているかもしれない
  • 近い井戸を実際に使っていたとは限らない
  • 地図上の距離と実際の行動は異なるかもしれない

ここから、

回帰分析ができることと、因果関係を明らかにすることは同じではない

という点を確認します。

学生に出す演習問題：基礎

  1. Snow.deaths の観測数を確認しなさい。
  2. 道路、死亡地点、井戸を同じ図に表示しなさい。
  3. 井戸を死亡地点とは異なる形で表示しなさい。
  4. 地図から、感染源として疑われる井戸を考えなさい。

学生に出す演習問題：発展

  1. 感染源をより厳密に調べるには、どのような追加データが必要でしょうか。
  2. この地図から言えることと言えないことを整理しなさい。
  3. 回帰分析を行うとすれば、目的変数と説明変数には何を使えばよいでしょうか。
  4. 因果関係を明らかにするためには、どのような比較が必要でしょうか。
