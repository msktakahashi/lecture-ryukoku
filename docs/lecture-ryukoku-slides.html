「データ分析と問題解決」の目標

演習の目標：

  • 解決したい問題を見つける

  • 問題の原因は何か仮説を立てる

  • 「データ分析」を通して問題の原因を探る

  • 解決策を見出す

この模擬授業では、

  • 19世紀のロンドンにおけるコレラ流行の原因究明と解決を題材に、

  • 当時のデータを使いながら実際にRを使って演習を行います

偉大な先人から学ぶ

  • 19世紀半ばのロンドンでコレラが大流行、多くの死者が出る（社会問題）

  • コレラが流行する原因は何か？

    • 瘴気（悪い空気）？（当時は「瘴気説」が主流）
    • 水質汚染？

  • 原因に応じて解決策を見出す

    • 瘴気が原因 -> 街の悪臭を消す対策（実際に行われた）
    • 水質汚染が原因 -> 水質改善、安全な飲料水の確保

偉大な先人から学ぶ

John Snow (1813-1858)

データの収集・分析でスノウが気づいたこと：

  • 水道を供給する会社によって住民のコレラによる死亡率が異なる
  • 死亡者の多くが、ある特定の井戸を利用していた
  • その井戸の近くの醸造所の従業員には重症者なし（独自の井戸を利用／水の代わりにビールを飲む）

-> 原因は水質にあるのでは？

偉大な先人から学ぶ

“コレラマップ”

  • Broad Streetの井戸（赤）周辺の死者が多い
  • 醸造所（緑）周辺では重症者なし
  • この井戸を利用停止にしたら死者数が減少

-> 水が原因であるという仮説をさらに支持

偉大な先人から学ぶ

解決策（その後の公衆衛生対策）

  • 上下水道の整備
  • 安全な飲料水の確保（水は沸騰させてから飲む）

-> コレラなど水系感染症の抑制

正しい原因を突き止めることで適切な対応策を立てることができた

井戸を追加する

それぞれの井戸周辺の死亡者数を計算

# 「周辺」を半径100m以内と定義
radius <- 100

# 各井戸と各死亡地点の組み合わせを作る
pump_case_distance <- tidyr::crossing(
  pump_locations |>
    transmute(
      pump_id = id,
      pump_e = Easting,
      pump_n = Northing
    ),
  cholera_cases |>
    transmute(
      case_id = id,
      Count,
      case_e = Easting,
      case_n = Northing
    )
) |>
  # 各井戸から各死亡地点までの距離を計算
  mutate(
    distance = sqrt(
      (case_e - pump_e)^2 +
      (case_n - pump_n)^2
    )
  )

それぞれの井戸周辺の死亡者数を計算

## 井戸ごとに半径100m以内の死亡者数を集計 ##
pump_deaths <- pump_case_distance |>
  group_by(pump_id, pump_e, pump_n) |>
  summarise(
    deaths_nearby = sum(Count[distance <= radius]),
    .groups = "drop"
  ) |>
  # 周辺死亡者数が多い順に並べる
  arrange(desc(deaths_nearby))

top2_pumps <- top2_pumps |>

pump1 <- top2_pumps |> slice(1)

回帰モデル

次のような回帰モデルを推定する

\[ DeathCount_i = \alpha + \beta RelativeDistance_i + u_i \]

もし1位の井戸に（相対的）に近いほど死者数が多いのであれば、 \[\beta < 0\] となるはず。

回帰分析

回帰分析で係数を推定してみる

## lm()で回帰モデルを推定 ##
model_linear <- lm(
  Count ~ relative_distance,
  data = cholera_cases2
)

summary(model_linear)

  • 我々の分析とジョン・スノウの分析は何が違うのだろうか？

回帰分析と本当に知りたいことの違い

私たちの回帰モデルは、

死亡が発生した地点の中で、1位の井戸に相対的に近い地点ほど死亡者数が多いか

を調べている

一方、本当に知りたいのは、

1位の井戸の水を利用すると、コレラで死亡する確率が高くなるか

スノウは井戸への距離を見ていたわけではなく、住民がどこの井戸を使っていたのかを調べた。

スノウは「例外」も調べた

  • 1位の井戸に近いにもかかわらず死亡者が少ない場所があった

醸造所（brewery）

  • 従業員は独自の井戸やビールを利用しており、原因となる井戸は（近くにあるが）利用していなかった

  • 実際にその井戸を使っているかどうかが重要

交絡因子

  • その井戸を使っていたからといって、井戸の水が原因であると言えるか？

  • 特定の井戸を使っている人は、そうでない人に比べて別の要因でコレラに罹りやすかったのかもしれない

  • スノウは、疑わしい井戸を使用禁止にしたら死者数が減少することも示した

さらに必要なデータ

より厳密に検証するにはどのような情報が必要か？

  • 各地点に住んでいた人数
  • 死亡しなかった人の情報
  • 各世帯が実際に使っていた井戸
  • 所得や衛生環境
  • 井戸を使用禁止にする前後の情報
